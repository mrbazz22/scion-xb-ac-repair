# 2010 Scion xB AC Repair Guide

iOS Home Screen-friendly HTML guide for replacing the AC compressor and receiver drier on a 2010 Scion xB with the 2AZ-FE engine.

## Parts Used
- A/C Compressor (new/reman)
- A/C Receiver Drier
- FOUR SEASONS 59007 A/C Refrigerant Oil — $7.24
- GPD 3411860 A/C Expansion Valve — $12.47
- UAC RS2584 A/C System O-Rings / Seals — $12.00

## Quick Start
1. Open `index.html` in Safari on iOS
2. Tap Share → Add to Home Screen
3. Launch from home screen for full-screen PWA experience

## Features
- Tabbed sections: Overview, Specs, Parts, Removal, Install, Recharge, Diagnose
- Torque specs from Toyota service manual
- Interactive checklist (saves state)
- Dark mode optimized for garage use
- Works offline once loaded

## Technical Specs
- **Refrigerant:** R-134a (HFC-134a)
- **Charge:** 450-550g (15.9-19.4 oz)
- **Oil:** ND-OIL 8 or equivalent
- **New compressor oil:** 90cc (3.0 fl oz)

## Torque Values
| Component | Torque |
|-----------|--------|
| Compressor stud bolts (E8 Torx) | 9.8 Nm (87 in-lbf) |
| Compressor mount bolts/nuts | 25 Nm (18 ft-lbf) |
| Discharge hose bolt | 9.8 Nm (87 in-lbf) |
| Suction hose bolt | 9.8 Nm (87 in-lbf) |
